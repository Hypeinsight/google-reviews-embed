Page Embed Codes (Standalone Landing Page)

Creates a dedicated review page - perfect for /reviews or /feedback pages.

📄 Page Embed Setup Instructions

  1. Create a blank HTML file (e.g., reviews.html) on the client's website
  2. Copy the complete HTML structure:
    <!DOCTYPE html>
    <html>
    <head>
      <meta charset="UTF-8">
      <meta name="viewport" content="width=device-width, initial-scale=1.0">
      <title>Leave a Review</title>
    </head>
    <body>
      [PASTE EMBED CODE HERE]
    </body>
    </html>
  3. Paste the embed code below between the <body> tags - replace [PASTE EMBED CODE HERE]
  4. Customize the data-page-title and data-page-subtitle attributes in the code
  5. Upload the file to the client's website (e.g., yoursite.com/reviews.html)
  6. Share the page URL via QR codes, emails, or direct links

⚠️ Important: This creates a standalone page that takes over the entire page. Do NOT add this to existing pages with headers/footers. For existing pages, use the "Button Embed" instead.
