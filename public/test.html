Test Configuration

Tenant: tenant_demo

Site: site_demo_main

Location: loc_demo_hq

Note: The review button should appear in the bottom-right corner of the page.

Setup Instructions

  1. Make sure the API server is running: npm run dev
  2. Ensure the database is set up with schema: psql -U your_user -d your_database -f db/schema.sql
  3. Seed the database with test data: npm run seed
  4. Open this page: http://localhost:3000/embed/test.html
  5. Look for the "Leave a Google Review" button in the bottom-right corner

# View feedback (check database)

Integration Example

To add this widget to any website, include the following script tag:

<script src="http://localhost:3000/embed/embed.js"
        data-tenant-id="tenant_demo"
        data-site-id="site_demo_main"
        data-location-id="loc_demo_hq"
        data-api-url="http://localhost:3000">
</script>
